# News Alarm · 新闻闹钟

新闻闹钟是一款 Android 新闻阅读与定时播报应用，聚合中英文新闻，并提供翻译、语音播报、新闻闹钟和休息提醒。

项目目前处于测试阶段。当前发布版本：**0.5.77**（versionCode 171）。

## 功能

- 中英文新闻聚合、分类浏览与来源管理。
- 英文新闻离线翻译、中文繁简转换。
- 新闻语音播报、悬浮播放器与媒体通知。
- 定时新闻闹钟、休息提醒与手机使用限制。

新闻、设置与诊断信息保存在本机，诊断信息不会自动上传。

## 系统要求

- Android 8.0（API 26）或更高版本
- ARM64 Android 设备

按使用的功能授予通知、精确闹钟或无障碍权限。部分手机还需允许后台运行；关机或强制停止应用后无法保证闹钟响铃。

部分来源的正文受登录、付费或网站访问限制影响，可能需要在原网站阅读。

## 安装测试包

[下载 NewsAlarm-0.5.77-debug.apk](./NewsAlarm-0.5.77-debug.apk)，或前往 [GitHub Releases](https://github.com/PlutaB/News-Alarm/releases/latest) 下载安装包。

下载后按系统提示允许浏览器或文件管理器安装未知来源应用。测试包使用调试签名，用于测试。
